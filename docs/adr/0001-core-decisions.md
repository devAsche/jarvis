# ADR-0001: 開発共通化と実行安全性

状態: 暫定採用（M0で環境検証後に確定） / 日付: 2026-09-28

## 背景

AntigravityとCodexの双方で同じ仕様を理解し、5時間枠/コンテキスト切替後も開発可能にする。近未来的なUIと実際の業務実行には、視覚状態/実行状態の一致と操作許可が必要。

## 決定

1. `C:\AI\jarvis`単一Gitリポジトリ、根元`AGENTS.md`を共通入口とする。固有の多段プロンプトは`prompts`、機能固有のルールは`.agents`で段階開示。
2. 実アプリはIDEと独立。M0/M1では外部API・有料推論を使わず、モックで端から端まで検証する。
3. 高リスク操作はサーバー側の決定的policyと強い人間承認により制御。音声だけの高価値取引は禁止。
4. UIはCSS/SVGを基礎とし、計測に合格した後にThree.jsへ移行。映像の固有デザインを複製しない。
5. 原則ひとつの作業ブランチ、並列時だけGit worktree。統合前のレビューを必須化。

## トレードオフ

初期に実データや超高精細3Dを使わないため、ビデオの演出や実事業価値は段階的に増える。その代わり誤発注・課金事故・トークン枯渇・仕様の迷走を抑えられる。別AI開発環境の固有機能にロックインしない。

## 再評価条件

M1受入合格後に実際の接続範囲・音声API・クラウド/キュー/DB製品を比較。権限境界や個人情報の方針を変える場合は新規ADRとユーザー承認が必要。
