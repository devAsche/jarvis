# 12 — クラウド常時稼働の計画（承認待ち）

状態: **未デプロイ・承認待ち**（2026-10-05）。ユーザーは「クラウドで常時稼働」を選択。AGENTS.mdにより、費用が発生する契約・本番設定・外部公開は、見積もりと明示の承認の後に行う。

## 必要な形

- 常に起動している Node サーバー1台（`npm run build && npm run start`）。JARVISはファイル保存（`JARVIS_DATA_DIR`）と、応答後にバックグラウンドで終わる読み取り処理を使うため、**サーバーレス（Vercel等）は不向き**。
- 永続ディスク（数百MBで足りる）。`JARVIS_DATA_DIR` をそこに向ける。
- HTTPS の公開URL（Webhook受信とログインのため。本番ではCookieにSecureが付く）。
- 30分ごとの定期実行（`POST /api/cron/sync`）。サービス内蔵のcron、または外部の無料スケジューラー。
- インスタンスは1台だけ（ログイン試行制限と保存がプロセス内のため）。
