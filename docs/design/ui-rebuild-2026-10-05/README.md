## 案D: SF HUD（ユーザー参考画像を受けた追加案）

ユーザーが「画像の感じ」（青いHUD調のデスクトップ。参考画像はリポジトリに入れていない）を好み、「SFかつ高級感のある豊かなUI」を要望（2026-10-05）。参考画像のロゴ・商標・映画由来の意匠（特定キャラクター、アーク型の三角形など）は使わず、抽象化した要素だけを採用した。

- 採用した要素: 黒に近い紺の背景と細いグリッド、発光する細線、目盛り付きの多重リング、角を落とした枠、日付ルーラー、円形のドック、引き出し線つきの注記。
- 試作: `prototypes/hud.html`。配色は「蒼」と「黒金」の2種類。状態（通常/照合中/承認待ち/承認後/エラー）と描画オフを切り替えられる。
- 構成: 上段に2026年10月の日付ルーラー（今日=5日、予定のある日に印）。左に日付ダイヤル・接続リング（0/4）・監査記録。中央にリングのコアを置き、3本の弧を3系統の照合（shopify/gmail/calendar fixture）に対応させ、出典の注記を引き出し線で結ぶ。右に判断パネル（金枠）・出典付きの朝の報告・サンプルの数字。下に円形のドック。
- 業務テキスト・金額・承認はすべてDOM。コアは2D canvasの代用で、採用時にR3Fで作る。描画オフでは静止SVG。
- 390px: ヘッダー→ルーラー→コア→状態→出典→入力→判断→報告→数字→日付/接続/記録の順で、ドックは下に固定。
- 懸念: 装飾が多く、描画負荷はA〜Cより高い（R3F版はリング本数とブルームの品質段階で調整する）。英字の小ラベル（AWAITING HUMAN等）は雰囲気用で、意味は必ず日本語の本文でも示す。

- 状態色（2026-10-05追加、ユーザー要望「蒼のUIのまま、状態ごとにコアをカラフルに」）: 画面の枠・文字は蒼のまま、コアと状態見出しだけ色を変える。待機=蒼 `#56c8ff`、照合中=紫電 `#a07bff`＋シアン、承認待ち=琥珀 `#ffb347`、記録済み=翠 `#3cf0a4`、エラー=紅 `#ff4d63`（外周が点滅）。コアの下に色と状態の凡例を常時表示し、色だけに頼らず日本語の状態名も出す。
